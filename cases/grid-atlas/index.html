Data and methodology

Grid Atlas uses Ember’s Yearly Electricity Data, updated on 17 November 2026. The dashboard covers electricity generation from 2000 through 2025.

Clean and fossil generation
Clean combines renewables and nuclear. Fossil includes coal, gas and other fossil sources. Shares divide generation by the total for the same place and year.
Year-over-year changes
Shares change in percentage points (pp). Generation changes are measured in TWh, except the total-generation KPI, which uses a relative percent change.
Coverage
Some places have gaps or report later than others. Missing years are excluded from rankings, and the world series is Ember’s published aggregate. Map boundaries are from Natural Earth.
